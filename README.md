# 🚀 Shoot the Circles! – A Python OpenGL Arcade Game

This is a simple 2D OpenGL game built using Python and PyOpenGL where you control a ship and shoot falling colorful circles to earn points!

---

## 🎮 How to Play

- **Move Left/Right:** Arrow keys ← →
- **Shoot:** Spacebar
- **Pause/Play:** Click the “Play/Pause” button
- **Restart Game:** Click the “Restart” button
- **Exit Game:** Click “Exit” or press `ESC`

---

## 🛠️ Features

- Randomly falling colorful circles
- Dynamic shooting mechanics with point-based collision
- Visual stars as background
- Game over logic on 3 misses
- Fully interactive UI buttons
